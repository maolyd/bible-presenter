# Bible data: sources, licences and importing

Bible text is kept separate from the program code:

* `data/bibles/` – the bundled source files plus `catalog.json` (name, language, licence, checksum).
* `%LOCALAPPDATA%\BiblePresenter\bibles.sqlite` – the library the program actually reads, created when you import.

## Bundled translations

| Code | Translation | Language | File | Format | Licence |
|---|---|---|---|---|---|
| **KJV** (default English) | King James Version (1769 text) | English | `eng-kjv.osis.xml` | OSIS XML | Public domain outside the UK (see below) |
| **LSG** (default French) | Louis Segond 1910 | French | `fra-lsg1910.beblia.xml` | Beblia XML | Public domain |

Where they come from:

* **KJV** – `eng-kjv.osis.xml` from the *open-bibles* collection (<https://github.com/seven1m/open-bibles>), an OSIS file generated by eBible.org's Haiola tool. Its own rights statement: *“This work is in the Public Domain … A United Kingdom Crown Copyright with no expiration date means that to print this translation in the United Kingdom, you need letters patent … This Crown Copyright has no effect outside of the UK.”* **Churches in the United Kingdom** should check the terms of the Crown's patentee (Cambridge University Press) for projecting/streaming; elsewhere it is public domain.
  You suggested a scan of the KJV on archive.org (`kjvtextbible`). That item is a scanned book (page images with OCR text), which does not reliably mark book/chapter/verse boundaries and contains OCR errors, so the same KJV text was taken from the verse-tagged OSIS file instead.
* **Louis Segond 1910** – `FrenchBible.xml` from <https://github.com/Beblia/Holy-Bible-XML-Format>. The 1910 revision of the Segond Bible is in the public domain; the transcriber states it may be used “at your own discretion, no need to ask for permission”. This transcription follows the 1910 spelling convention of capitals without accents (*Eternel*), and **uses KJV verse numbering** (for example Psalm titles are part of verse 1, so Psalm 51:1 is the same verse in KJV and LSG). Some printed LSG editions number Psalm titles separately (e.g. *Psaume 51:3*); this app uses the KJV-style numbers for both languages.

Verification done for this project (see `tests/test_full_bibles.py`):

* KJV: 66 books, 1,189 chapters, 31,102 verses. LSG: 66 / 1,189 / 31,102.
* **KJV and LSG contain exactly the same verse numbers** — every English verse has its French partner.

## How verses are paired

Every translation is stored by **canonical book number (1–66), chapter and verse**. English and French verses are matched on that key, never by position. If a verse exists in only one translation, the slide and the centre panel show “*[Verse 8:37 is not in this translation — the verse numbering or source text differs.]*” on the side where it is missing.

## Importing another Bible

**Only import a Bible you are allowed to use.** Most modern translations (NIV, ESV, NLT, Segond 21, Bible du Semeur, NBS, Colombe…) are copyrighted; you need the publisher's permission (often a church licence) and a file they provide. Do not copy text from websites.

1. Click the **KJV** (or **LSG**) button at the top → **Bible library…** → **Import Bible file…**
2. Choose the file. The program identifies the format and shows a review screen: name, language, the number of books/chapters/verses, whether all 66 books are present, skipped books (e.g. Apocrypha), empty verses, duplicate and invalid references.
3. Check/adjust the **name**, a short **code** (e.g. `NEG`), the **language** and the **licence/permission**, then click **Import**.
4. If a translation with the same code exists, you are asked whether to replace it.

Nothing is changed until you click Import, and the import is a single database transaction: if anything fails, the previous library is kept exactly as it was. Bibles with fewer than 66 books are marked **partial** and the setup screen keeps asking for a complete Bible.

### Supported formats

These are existing, publicly documented formats (the program does not invent its own):

| Format | How it is recognised | Notes |
|---|---|---|
| **USFX XML** (eBible.org) | root element `<usfx>` | `<book id="JHN">`, `<c id="3"/>`, `<v id="16"/>…<ve/>`. Footnotes `<f>`, cross-references `<x>`, headings `<s>`, Psalm titles `<d>` are left out. Spec: <https://ebible.org/usfx/> |
| **OSIS XML** | root element `<osis>` | Both `<verse osisID="John.3.16">text</verse>` and milestone `<verse sID=…/>text<verse eID=…/>` forms. Notes and titles are left out. Spec: <https://crosswire.org/osis/> |
| **Zefania XML** | root element `<XMLBIBLE>` | `<BIBLEBOOK bnumber="43"><CHAPTER cnumber="3"><VERS vnumber="16">`. `<NOTE>` is left out. |
| **Beblia XML** | root `<bible>` with `<book number>` / `<chapter number>` / `<verse number>` | Format used at <https://github.com/Beblia/Holy-Bible-XML-Format> |
| **eBible.org VPL text** | lines like `JHN 3:16 For God so loved…` | USFM 3-letter book codes, one verse per line, UTF-8 |
| **.zip** | a zip containing one of the above | e.g. eBible.org downloads (`…_usfx.zip`, `…_vpl.zip`) |

Books are numbered 1–66 in the usual Protestant order (Genesis = 1, Malachi = 39, Matthew = 40, Revelation = 66). Books outside these 66 are skipped and listed in the import report.

### Where to find more legally distributable Bibles

* **eBible.org** (<https://ebible.org/download.php>) lists many public-domain and Creative-Commons Bibles with their licence on each page; download the *USFX* or *VPL* zip and import it directly. For French, for example, *fraLSG* (Louis Segond 1910), *frasbl* (Bible libre, CC BY-SA) and others.
* **open-bibles** (<https://github.com/seven1m/open-bibles>) – public-domain OSIS/USFX/Zefania files, including *French Ostervald 1996*.
* Publishers of copyrighted translations – ask them for a licensed data file for presentation software.

Always keep a note of the licence: the import screen has a *Licence / permission* field, and **Translation info** shows it later.
